# Osu-Phantom

A library to track recent user scores and essentially create a new ranking based off only on that.

PP calculation is grabbed from the osu API if it exists, otherwise it's calculated manually by
[crosu-pp](https://github.com/Minoxs/crosu-pp), which is a shared library wrapper of [rosu-pp](https://github.com/MaxOhn/rosu-pp).
